# Exercícios de Python - Programação Estruturada

Este repositório reúne uma coleção de exercícios e exemplos desenvolvidos durante a primeira fase da disciplina de Programação Estruturada. A ideia é registrar, de forma prática, o que aprendi sobre Python nos primeiros passos da minha formação na área.

Embora ainda seja um conhecimento inicial, este material representa uma base importante em lógica de programação, estruturação de algoritmos e uso da linguagem Python para resolver problemas simples e cotidianos.

## O que aprendi

Ao longo dessa fase, tive contato com vários conceitos fundamentais da programação, entre eles:

- Conceitos básicos de algoritmos e lógica de programação
- Criação e utilização de variáveis
- Entrada e saída de dados com input() e print()
- Operadores aritméticos e matemáticos
- Operadores de comparação e expressões condicionais
- Estruturas de decisão com if, elif e else
- Operadores lógicos como and, or e not
- Laços de repetição com while e for
- Controle de fluxo em programas
- Uso de acumuladores e contadores
- Desenvolvimento de soluções para problemas simples
- Formatação de mensagens e saída de dados em tela
- Manipulação básica de textos e números

## Principais temas abordados

### 1. Fundamentos de Python

Nessa parte, aprendi a escrever programas simples, entender a estrutura básica de um script Python e trabalhar com variáveis para armazenar dados e realizar operações.

### 2. Entrada e saída de dados

Estudei como capturar informações fornecidas pelo usuário e exibir resultados na tela, o que foi essencial para criar programas interativos.

### 3. Estruturas de decisão

Aprendi a tomar decisões dentro dos programas, usando condições para executar diferentes blocos de código dependendo de situações específicas.

### 4. Estruturas de repetição

Conheci a diferença entre os laços while e for, além de compreender como usar repetições para automatizar tarefas e processar várias entradas.

### 5. Operadores lógicos

Estudei como combinar condições para construir decisões mais completas e precisas em algoritmos.

### 6. Algoritmos simples

Pratiquei a resolução de exercícios envolvendo cálculo de médias, somas, idade, tabuada, descontos, salário, números pares e outros problemas básicos.

## Estrutura da pasta

- algoritmos.py: reúne vários exercícios introdutórios com operações básicas, cálculo de idade, salário, descontos e outros problemas simples.
- soma.py: contém exemplos relacionados a somas, contadores e uso de estruturas de repetição.
- estrutura de decisao/: pasta com exercícios voltados ao estudo de estruturas de decisão.
- exercicios-for/: pasta com exercícios práticos usando o laço for.
- funções para str/: pasta com estudos sobre formatação de texto e números em Python.
- OP_logicos/: pasta com exemplos e exercícios sobre operadores lógicos.
